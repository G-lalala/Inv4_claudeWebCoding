# 動画出力機能 タスク一覧

## タスク

### 動画エンコード

#### 1. エンコード処理
- [ ] `videoEncoder.ts` ファイル作成
- [ ] FFmpeg エンコード設定の定義
- [ ] エンコード実行処理:
  - [ ] コーデック: H.264 (libx264)
  - [ ] プリセット: medium
  - [ ] CRF: 23
  - [ ] ピクセルフォーマット: yuv420p
  - [ ] 音声: AAC 192kbps
  - [ ] movflags: +faststart
- [ ] エンコード進捗の取得（FFmpeg stderr パース）
- [ ] エラーハンドリング

## 備考
- ダウンロード後の削除は確実に実行されるようエラーハンドリングを徹底
- クリーンアップジョブで漏れたファイルも確実に削除
- ストリーミング配信により、大きなファイルでもメモリ効率良く配信
