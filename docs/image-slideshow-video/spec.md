# 画像スライドショー動画生成機能 仕様書

## 概要

複数の画像ファイルをアップロードし、それらを自動的にスライドショー動画として生成・出力するWebアプリケーション機能。

## ユーザー要求

> 画像を複数枚アップロードしたらその画像をスライドショーの動画として出力する機能を作成したい

## 機能要件

### 1. 画像アップロード機能

#### 基本機能
- 複数画像の一括アップロード
- ドラッグ&ドロップによるアップロード対応
- ファイル選択ダイアログからの選択

#### 対応フォーマット
- JPEG (.jpg, .jpeg)
- PNG (.png)
- GIF (.gif)
- WebP (.webp)

#### 制約
- 最大ファイルサイズ: 1ファイルあたり10MB
- 最大アップロード枚数: 100枚
- 最小アップロード枚数: 2枚

#### アップロード後の機能
- アップロードした画像のサムネイル表示
- 画像の順序変更（ドラッグ&ドロップ）
- 個別画像の削除
- 画像の追加

### 2. スライドショー設定機能

#### 基本設定
- **各画像の表示時間**
  - 範囲: 1秒〜10秒
  - デフォルト: 3秒
  - 0.5秒刻みで調整可能

- **トランジション効果**
  - フェード
  - スライド（左→右）
  - スライド（右→左）
  - スライド（上→下）
  - スライド（下→上）
  - ズームイン
  - ズームアウト
  - なし
  - デフォルト: フェード

- **トランジション時間**
  - 範囲: 0.5秒〜3秒
  - デフォルト: 1秒
  - 0.5秒刻みで調整可能

#### 出力設定

- **動画解像度**
  - 1920x1080 (Full HD) - デフォルト
  - 1280x720 (HD)
  - 640x480 (SD)

- **フレームレート**
  - 固定: 30fps

- **出力フォーマット**
  - MP4 (H.264コーデック)

- **画像のフィット方法**
  - カバー: 画像をトリミングしてフレーム全体を埋める
  - コンテイン: 画像全体を表示、余白あり（デフォルト）
  - ストレッチ: 画像を引き伸ばしてフレームに合わせる

#### オプション設定

- **背景色**
  - カラーピッカーでの選択
  - デフォルト: 黒 (#000000)
  - 適用対象: コンテインモードで画像がフレームより小さい場合の余白

- **BGM追加（オプション）**
  - 対応フォーマット: MP3, WAV
  - 最大ファイルサイズ: 20MB
  - 音量調整: 0%〜100%（デフォルト: 50%）
  - 動画の長さに合わせてループまたはカット

### 3. 動画生成機能

#### 処理フロー
1. ユーザーが画像と設定パラメータを確認
2. 「動画を生成」ボタンをクリック
3. 画像とパラメータをサーバーに送信
4. サーバー側でFFmpegを使用して動画処理
5. 進捗状況をリアルタイムで表示
6. 生成完了後、動画をストリーミング送信してプレビュー・ダウンロード
7. ダウンロード完了後、サーバー側の動画ファイルを即座に削除

#### 処理状態管理
- **キュー管理**: 複数リクエストの順次処理
- **進捗表示**: 0%〜100%のプログレスバー
- **処理時間の目安表示**: 予想処理時間の表示
- **エラーハンドリング**: エラー発生時のメッセージ表示
- **タイムアウト**: 最大5分で処理完了しない場合はタイムアウト

#### 進捗状況の詳細
- 画像処理中: X/Y枚処理完了
- 動画エンコード中
- 最終処理中

### 4. プレビュー・ダウンロード機能

#### プレビュー
- 生成された動画のブラウザ内再生
- 再生コントロール（再生/一時停止、シーク、音量調整）

#### ダウンロード
- 生成された動画のダウンロード
- ファイル名: slideshow_YYYYMMDD_HHMMSS.mp4
- ダウンロード完了後、サーバーから即座に動画ファイルを削除

## 技術仕様

### フロントエンド技術スタック
- **フレームワーク**: Next.js 14+ (App Router)
- **言語**: TypeScript
- **スタイリング**: Tailwind CSS
- **フォーム管理**: React Hook Form
- **状態管理**: Zustand または React Context API
- **ファイルアップロード**: react-dropzone
- **UI コンポーネント**: Headless UI または Radix UI

### バックエンド技術スタック
- **API**: Next.js API Routes
- **動画生成**: FFmpeg
- **ファイル管理**: Node.js File System API
- **一時ストレージ**: サーバーローカルファイルシステム

### 動画生成パラメータ（FFmpeg）
- **ビデオコーデック**: libx264
- **オーディオコーデック**: aac（BGM使用時）
- **ピクセルフォーマット**: yuv420p
- **プリセット**: medium（バランス重視）
- **CRF値**: 23（品質とファイルサイズのバランス）

### データフロー

```
[クライアント]
  ↓ 画像アップロード
[一時ストレージ: /tmp/uploads/{sessionId}]
  ↓ 設定送信
[API: /api/generate-video]
  ↓ FFmpeg処理
[一時ストレージ: /tmp/videos/{videoId}.mp4]
  ↓ ストリーミング送信
[クライアント（プレビュー・ダウンロード）]
  ↓ 送信完了後
[サーバー: 動画ファイルを即座に削除]
```

## 制約事項

### システム制約
- **同時処理数**: 最大3リクエスト（キュー超過時は待機）
- **生成動画の保存**: ダウンロード完了後に即座に削除（サーバーには保存しない）
- **プレビュー用動画**: ブラウザメモリ内で再生、サーバーからストリーミング後に削除
- **最大動画長**: 10分
- **アップロード一時ファイル**: セッション終了または24時間後に削除

### パフォーマンス目標
- **画像アップロード**: 100枚で30秒以内
- **動画生成時間**: 1分あたりの動画を30秒以内で生成
- **初回ページ表示**: 3秒以内
- **インタラクション応答**: 100ms以内

## セキュリティ要件

### ファイル検証
- **MIMEタイプチェック**: 厳密なファイルタイプ検証
- **ファイルサイズ検証**: クライアント・サーバー両方で実施
- **ファイル拡張子検証**: ホワイトリスト方式
- **画像の妥当性検証**: 実際に画像として読み込み可能かチェック

### セキュリティ対策
- **CSRF対策**: Next.jsのデフォルト対策を使用
- **レート制限**: 1IPあたり1時間に10リクエスト
- **セッション管理**: 一時ファイルのセッション分離
- **パス・トラバーサル対策**: ファイル名のサニタイズ
- **FFmpegインジェクション対策**: パラメータのエスケープと検証

## エラーハンドリング

### クライアント側エラー
- **ファイルサイズ超過**: 「ファイルサイズが大きすぎます（最大10MB）」
- **対応していないフォーマット**: 「対応していないファイル形式です」
- **枚数制限超過**: 「画像は最大100枚までです」
- **画像不足**: 「画像を2枚以上選択してください」

### サーバー側エラー
- **処理タイムアウト**: 「処理時間が上限を超えました。画像枚数を減らしてお試しください」
- **ストレージ不足**: 「一時的にサービスが利用できません」
- **FFmpegエラー**: 「動画生成中にエラーが発生しました」
- **不正なリクエスト**: 「無効なリクエストです」

## 参考情報

### FFmpeg コマンド例
```bash
# 基本的なスライドショー生成
ffmpeg -framerate 1/3 -pattern_type glob -i 'images/*.jpg' \
  -vf "scale=1920:1080:force_original_aspect_ratio=decrease,pad=1920:1080:(ow-iw)/2:(oh-ih)/2,format=yuv420p" \
  -c:v libx264 -preset medium -crf 23 -r 30 output.mp4
```
