# 画像アップロード機能 仕様書

## 概要
ユーザーが複数の画像を選択・アップロードし、フロントエンドで圧縮してからサーバーに送信する機能。アップロード後は確認画面で画像一覧を表示する。

## 要件

### 対応画像枚数
- **最小**: 3枚
- **最大**: 50枚
- バリデーション: 枚数が範囲外の場合はエラーメッセージを表示

### 対応画像フォーマット
- iOS形式: HEIC、HEIF
- Android形式: JPG、JPEG、PNG、WebP
- その他: BMP、GIF（静止画として扱う）

### 画像処理

#### フロントエンド圧縮
- **目的**: ユーザーの快適な操作体験を確保
- **処理タイミング**: 画像選択後、アップロード前
- **圧縮方法**:
  - HEIC/HEIF形式はJPEGに変換
  - 長辺を1920px以下にリサイズ（アスペクト比維持）
  - JPEG品質: 85%
  - 目標ファイルサイズ: 1枚あたり500KB〜1MB程度

#### バリデーション
- **ファイル形式チェック**: MIMEタイプと拡張子の両方で検証
- **ファイルサイズチェック**: 圧縮前10MB/枚、圧縮後2MB/枚
- **画像の正当性チェック**: 破損していないか確認

### 確認画面

#### 表示内容
- アップロードした画像のサムネイル一覧（グリッドレイアウト）
- 各画像のファイル名、サイズ表示
- 合計枚数の表示
- 削除ボタン（個別削除可能）
- 画像の並び替え機能（ドラッグ&ドロップ）

#### アクション
- **戻るボタン**: 画像選択画面に戻る
- **動画を生成ボタン**: 次の処理（スライドショー生成）へ進む

## 技術仕様

### フロントエンド

#### 使用ライブラリ
- **画像圧縮**: `browser-image-compression` または `compressorjs`
- **HEIC変換**: `heic2any`
- **ドラッグ&ドロップ**: `react-beautiful-dnd` または HTML5 Drag and Drop API

#### 実装ファイル
- `app/components/ImageUploader.tsx`: 画像選択・アップロード UI
- `app/components/ImagePreview.tsx`: 確認画面 UI
- `app/utils/imageCompression.ts`: 画像圧縮ロジック
- `app/utils/imageValidation.ts`: バリデーションロジック

### バックエンド

#### API エンドポイント
- `POST /api/upload`: 圧縮済み画像を受け取り、一時ディレクトリに保存
  - リクエスト: multipart/form-data
  - レスポンス: アップロード成功時は画像ID配列を返す

#### 一時ストレージ
- **保存先**: `/tmp/uploads/{session-id}/`
- **ファイル名**: `{uuid}.jpg`
- **メタデータ**: `metadata.json`（画像順序、元のファイル名等）

## エラーハンドリング

### クライアントサイド
- 枚数不足/超過: 「画像は3枚以上50枚以下でアップロードしてください」
- 非対応フォーマット: 「対応していないファイル形式です」
- ファイルサイズ超過: 「ファイルサイズが大きすぎます」
- 圧縮失敗: 「画像の処理に失敗しました。再度お試しください」

### サーバーサイド
- アップロード失敗: 500エラー、リトライ可能メッセージ
- ディスク容量不足: 503エラー、一時的なサービス停止通知

## 制約事項
- ブラウザによってはHEIC形式の変換に時間がかかる場合がある
- 大量の画像（30枚以上）をアップロードする場合、圧縮処理に数秒かかる
- オフライン環境では動作しない

## セキュリティ
- ファイル拡張子の偽装を防ぐため、MIMEタイプを厳密にチェック
- アップロードされたファイルはサーバーサイドでも再バリデーション
- セッションIDはUUIDv4を使用してパス推測を防止
