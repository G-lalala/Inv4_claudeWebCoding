# 画像アップロード機能 タスク一覧

## タスク

### フロントエンド実装

#### 1. 画像選択UI
- [ ] `ImageUploader.tsx` コンポーネントを作成
- [ ] ファイル選択ボタンの実装（複数選択対応）
- [ ] ドラッグ&ドロップエリアの実装
- [ ] 選択された画像のプレビュー表示

#### 2. 画像圧縮処理
- [ ] `imageCompression.ts` ユーティリティ作成
- [ ] HEIC/HEIF → JPEG 変換機能の実装（heic2any）
- [ ] 画像リサイズ機能の実装（長辺1920px以下）
- [ ] JPEG品質85%での圧縮処理
- [ ] 圧縮進捗表示（プログレスバー）

#### 3. バリデーション
- [ ] `imageValidation.ts` ユーティリティ作成
- [ ] 画像枚数チェック（3〜50枚）
- [ ] ファイル形式チェック（MIME + 拡張子）
- [ ] ファイルサイズチェック（圧縮前10MB、圧縮後2MB）
- [ ] エラーメッセージ表示コンポーネント

#### 4. 確認画面
- [ ] `ImagePreview.tsx` コンポーネントを作成
- [ ] グリッドレイアウトでサムネイル表示
- [ ] 各画像の情報表示（ファイル名、サイズ）
- [ ] 個別削除ボタンの実装
- [ ] ドラッグ&ドロップで並び替え機能
- [ ] 合計枚数の表示
- [ ] 「戻る」「動画を生成」ボタン

### バックエンド実装

#### 5. API エンドポイント
- [ ] `app/api/upload/route.ts` を作成
- [ ] multipart/form-data の受信処理
- [ ] 画像ファイルのバリデーション（サーバーサイド）
- [ ] セッションID生成（UUIDv4）
- [ ] 一時ディレクトリへの保存処理
- [ ] メタデータJSONの生成・保存
- [ ] レスポンス返却（画像ID配列）

#### 6. ストレージ管理
- [ ] 一時ディレクトリ作成処理（/tmp/uploads/{session-id}/）
- [ ] ファイル保存処理（UUID.jpg）
- [ ] メタデータ管理（metadata.json）
- [ ] エラーハンドリング（ディスク容量不足等）

### テスト

#### 7. ユニットテスト
- [ ] 画像圧縮ロジックのテスト
- [ ] バリデーションロジックのテスト
- [ ] ファイル形式変換のテスト

#### 8. 統合テスト
- [ ] 画像アップロードフローの E2E テスト
- [ ] 各種エラーケースのテスト
- [ ] 最小枚数（3枚）のテスト
- [ ] 最大枚数（50枚）のテスト

### ドキュメント・その他

#### 9. 依存パッケージインストール
- [ ] `browser-image-compression` または `compressorjs`
- [ ] `heic2any`
- [ ] `react-beautiful-dnd` または代替ライブラリ
- [ ] `uuid`

#### 10. エラーメッセージ定義
- [ ] エラーメッセージ定数の定義
- [ ] 多言語対応の準備（必要に応じて）

## 優先順位

### Phase 1（基本機能）
1. 画像選択UI
2. 画像圧縮処理
3. バリデーション
4. API エンドポイント
5. ストレージ管理

### Phase 2（UX向上）
6. 確認画面
7. ドラッグ&ドロップ並び替え
8. 圧縮進捗表示

### Phase 3（品質保証）
9. テスト実装
10. エラーハンドリング強化

## 依存関係
- Phase 1 完了後、スライドショー生成機能の開発が可能
- 確認画面の並び順が、動画の画像順序に影響

## 備考
- HEIC変換はブラウザによって処理時間が異なる可能性があるため、ローディング表示必須
- セッションIDは他の機能でも使用するため、セッション管理の設計が重要
