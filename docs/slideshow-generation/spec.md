# スライドショー生成機能 仕様書

## 概要
アップロードされた画像を使用して、Ken Burns効果とランダムトランジションを組み合わせた静かで落ち着いた雰囲気のスライドショー動画を生成する機能。

## 要件

### 表示時間
- **基本表示時間**: 1枚あたり3秒
- **AI最適化**: 生成AIが画像の内容を分析し、3〜5秒の範囲で最適な表示時間を判断
- **動画全体尺**: 画像枚数 × 表示時間（可変）

### Ken Burns効果

#### 概要
写真に動きを与えるエフェクト（ゆっくりとしたズームとパン）

#### 仕様
- **動きの種類**:
  - ズームイン（中央から拡大）
  - ズームアウト（拡大から中央へ）
  - パン左（左へ移動しながらズーム）
  - パン右（右へ移動しながらズーム）
  - パン上（上へ移動しながらズーム）
  - パン下（下へ移動しながらズーム）
- **動きの速度**: ゆっくり（静かで落ち着いた印象）
- **ズーム倍率**: 1.0x 〜 1.2x（控えめ）
- **適用**: 全ての画像に適用（ランダムまたは順番）

### トランジション効果

#### 概要
画像から画像への切り替え効果

#### 効果パターン
1. **フェード**: 溶け込むように切り替え
2. **クロスディゾルブ**: 重なりながら切り替え
3. **スライド（横）**: 横方向にスライド
4. **スライド（縦）**: 縦方向にスライド
5. **ズームフェード**: ズームしながらフェード

#### 仕様
- **適用方法**: 複数パターンからランダムに選択
- **切り替え時間**: 0.5〜1秒
- **滑らかさ**: イージング関数を使用（ease-in-out）

### 画像処理

#### アスペクト比調整
- **動画アスペクト比**: 16:9（1920×1080）
- **画像の扱い**:
  - 16:9以外の画像: アスペクト比を維持してセンタリング
  - 余白: ブラックバー（黒帯）を追加
  - クロップは行わない（元の画像を尊重）

#### カラーグレーディング
- **基本方針**: 元の色味を保持
- **調整**: なし（ユーザーの画像をそのまま使用）

### AI による表示時間最適化

#### 使用モデル
- GPT-4 Vision、Claude 3.5 Sonnet、またはオープンソースモデル

#### 分析内容
- 画像の複雑さ（情報量）
- 被写体の数
- テキストの有無
- 色の豊富さ

#### 判断ロジック
- シンプルな画像: 3秒
- 標準的な画像: 4秒
- 複雑な画像: 5秒

## 技術仕様

### 動画生成エンジン
- **使用ライブラリ**: FFmpeg
- **実装方法**: Node.js から FFmpeg をサブプロセスとして実行
- **処理フロー**:
  1. 画像を一時ディレクトリから読み込み
  2. Ken Burns効果を適用（FFmpegのscale, zoomフィルター）
  3. トランジション効果を適用（xfadeフィルター）
  4. BGMと結合（別機能で処理）
  5. MP4形式でエンコード

### FFmpeg コマンド例

```bash
ffmpeg -loop 1 -t 3 -i image1.jpg \
       -loop 1 -t 4 -i image2.jpg \
       -filter_complex "\
         [0:v]scale=1920:1080:force_original_aspect_ratio=decrease,\
              pad=1920:1080:(ow-iw)/2:(oh-ih)/2,\
              zoompan=z='zoom+0.002':d=75:s=1920x1080[v0];\
         [1:v]scale=1920:1080:force_original_aspect_ratio=decrease,\
              pad=1920:1080:(ow-iw)/2:(oh-ih)/2,\
              zoompan=z='1.2-zoom*0.002':d=100:s=1920x1080[v1];\
         [v0][v1]xfade=transition=fade:duration=1:offset=2[out]" \
       -map "[out]" -c:v libx264 -pix_fmt yuv420p output.mp4
```

### 実装ファイル
- `app/api/generate/route.ts`: 動画生成APIエンドポイント
- `app/lib/ffmpeg.ts`: FFmpeg実行ラッパー
- `app/lib/kenBurns.ts`: Ken Burns効果の生成ロジック
- `app/lib/transitions.ts`: トランジション効果の定義
- `app/lib/aiAnalyzer.ts`: AI画像分析ロジック

## エラーハンドリング

### 想定エラー
- FFmpeg実行失敗: エンコードエラー、コーデック問題
- メモリ不足: 大量の画像処理時
- AI API失敗: API制限、ネットワークエラー

### 対応
- FFmpeg失敗: リトライ（最大3回）、エラーログ記録
- メモリ不足: 処理を分割、または枚数制限の案内
- AI失敗: デフォルト値（4秒）を使用してフォールバック

## パフォーマンス

### 目標処理時間
- 10枚の画像: 約10〜15秒
- 30枚の画像: 約30〜40秒
- 50枚の画像: 約50〜60秒

### 最適化
- 並列処理: 可能な部分は並列化
- キャッシュ: 同じ画像の再処理を避ける
- プログレス通知: WebSocketまたはポーリングで進捗を返す

## 制約事項
- FFmpegのインストールが必要（Dockerイメージに含める）
- AI分析により処理時間が増加する可能性
- 大量の画像処理は時間がかかる

## セキュリティ
- FFmpegコマンドインジェクション対策（入力パスの厳格な検証）
- 一時ファイルの適切な権限設定
