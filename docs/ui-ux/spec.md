# UI/UX実装 仕様書

## 概要
ユーザーが直感的に操作でき、快適に動画を生成できるインターフェースを提供する。ゲストユーザーでも迷わず使える シンプルで洗練されたデザイン。

## 要件

### 画面構成

#### 1. ランディングページ
- **目的**: アプリケーションの説明と利用開始
- **内容**:
  - アプリ名とキャッチコピー
  - 簡潔な説明文（3〜5行）
  - デモ動画またはサンプル画像
  - 「画像をアップロード」ボタン（CTA）
  - 使い方の簡単な説明（3ステップ）

#### 2. 画像アップロード画面
- **目的**: 画像の選択とアップロード
- **内容**:
  - ドラッグ&ドロップエリア
  - 「ファイルを選択」ボタン
  - 選択された画像のプレビュー（グリッド表示）
  - アップロード中のプログレスバー
  - 枚数表示（「3/50枚」など）

#### 3. 確認画面
- **目的**: アップロードした画像の最終確認
- **内容**:
  - 画像のサムネイル一覧（グリッドレイアウト）
  - 並び替え機能（ドラッグ&ドロップ）
  - 個別削除ボタン
  - 合計枚数と動画の長さの推定表示
  - 「戻る」ボタン
  - 「動画を生成」ボタン（CTA）

#### 4. 処理中画面
- **目的**: 動画生成中の待機とフィードバック
- **内容**:
  - ローディングアニメーション
  - プログレスバー（可能であれば進捗率表示）
  - 処理ステータスメッセージ:
    - 「画像を分析中...」
    - 「スライドショーを生成中...」
    - 「BGMを追加中...」
    - 「動画をエンコード中...」
  - 推定残り時間（可能であれば）

#### 5. 完了画面
- **目的**: 完了通知と次のアクション
- **内容**:
  - 完了メッセージ「ダウンロードが完了しました！」
  - 「新しいスライドショーを作成」ボタン
  - サポートリンク（必要に応じて）

#### 6. エラー画面
- **目的**: エラー時のユーザーサポート
- **内容**:
  - エラーメッセージ（分かりやすい言葉で）
  - 「戻る」ボタン
  - 「リトライ」ボタン（必要に応じて）
  - サポート連絡先（必要に応じて）

### デザイン方針

#### カラーパレット
- **プライマリ**: 落ち着いた青系（#4A90E2）
- **セカンダリ**: アクセント用の暖色系（#F5A623）
- **背景**: ライトグレーまたは白（#F9F9F9, #FFFFFF）
- **テキスト**: ダークグレー（#333333）

#### フォント
- **見出し**: 太めのサンセリフ（例: Inter Bold）
- **本文**: 読みやすいサンセリフ（例: Inter Regular）
- **サイズ**:
  - 見出し: 24px〜32px
  - 本文: 16px
  - キャプション: 14px

#### レイアウト
- **レスポンシブ**: モバイル、タブレット、デスクトップ対応
- **最大幅**: 1200px（デスクトップ）
- **余白**: 適切なスペーシング（16px, 24px, 32px）

### インタラクション

#### ボタン
- **スタイル**: 角丸、シャドウ、ホバー効果
- **サイズ**: 大きめ（高さ48px以上）
- **状態**:
  - デフォルト
  - ホバー（色が濃くなる）
  - アクティブ（押した感じ）
  - 無効（グレーアウト）

#### アニメーション
- **トランジション**: スムーズ（0.2s ease-in-out）
- **ローディング**: 回転アニメーション、スケルトンスクリーン
- **フェードイン**: 画面遷移時

#### フィードバック
- **成功**: 緑のチェックマーク、成功メッセージ
- **エラー**: 赤のアイコン、エラーメッセージ
- **警告**: 黄色のアイコン、警告メッセージ

### アクセシビリティ
- **コントラスト**: WCAG AA準拠（4.5:1以上）
- **キーボード操作**: Tab、Enter、Escapeキーに対応
- **スクリーンリーダー**: aria-label、alt属性の適切な設定
- **フォーカス表示**: アウトラインを明確に表示

## 技術仕様

### 使用ライブラリ
- **UIコンポーネント**: shadcn/ui または Headless UI
- **スタイリング**: Tailwind CSS
- **アニメーション**: Framer Motion
- **ドラッグ&ドロップ**: react-beautiful-dnd または dnd-kit
- **アイコン**: Lucide React または Heroicons

### 実装ファイル
- `app/page.tsx`: ランディングページ
- `app/upload/page.tsx`: アップロード画面
- `app/confirm/page.tsx`: 確認画面
- `app/processing/page.tsx`: 処理中画面
- `app/complete/page.tsx`: 完了画面
- `app/error/page.tsx`: エラー画面
- `app/components/ui/*`: 共通UIコンポーネント

### 状態管理
- **ローカル状態**: React useState
- **グローバル状態**: Context API または Zustand
- **セッション管理**: sessionStorage（セッションID保持）

## ユーザーフロー

### 正常系フロー
1. ランディングページ表示
2. 「画像をアップロード」ボタンクリック
3. 画像選択・アップロード
4. 確認画面で最終確認
5. 「動画を生成」ボタンクリック
6. 処理中画面でローディング表示
7. 完了画面で完了メッセージ表示
8. 自動ダウンロード開始

### エラーフロー
- 画像枚数不足/超過 → エラーメッセージ表示、アップロード画面に戻る
- アップロード失敗 → リトライボタン表示
- 動画生成失敗 → エラー画面表示、「戻る」ボタン

## エラーメッセージ

### クライアントサイド
- 「画像は3枚以上50枚以下でアップロードしてください」
- 「対応していないファイル形式です。JPG、PNG、HEICなどの画像をアップロードしてください」
- 「ファイルサイズが大きすぎます。1枚10MB以下の画像をアップロードしてください」
- 「画像の処理に失敗しました。再度お試しください」

### サーバーサイド
- 「サーバーエラーが発生しました。しばらくしてから再度お試しください」
- 「処理がタイムアウトしました。画像枚数を減らしてお試しください」
- 「一時的にサービスが利用できません。しばらくしてから再度お試しください」

## パフォーマンス
- **ページ読み込み**: 3秒以内（初回）
- **画像プレビュー**: 即座に表示
- **トランジション**: スムーズ（60fps）

## セキュリティ
- **XSS対策**: ユーザー入力のサニタイズ
- **CSRF対策**: APIトークン使用
- **セッションID**: セキュアな生成と保持

## 制約事項
- JavaScriptが無効の場合は動作しない
- 古いブラウザ（IE11等）は非対応
