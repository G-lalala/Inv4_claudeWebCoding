## 依存関係
- **依存**: 全機能（各APIエンドポイントが必要）

## 備考
- デザインはシンプルかつ直感的に
- ローディング時間が長い場合のUX配慮が重要
- モバイルファーストでデザイン
- アクセシビリティは初期段階から考慮
