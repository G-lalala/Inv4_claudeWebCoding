# BGM管理機能 仕様書

## 概要
スライドショー動画の長さに応じて、最適なBGMを自動的に選択し、動画の尺に合わせて調整（フェードアウト）する機能。

## 要件

### BGM素材

#### 楽曲数
- **合計**: 5曲を事前に用意

#### 楽曲の選定基準
- **雰囲気**: 静かで落ち着いた感動的な曲
- **ジャンル**: ピアノ、アコースティック、アンビエント、クラシック等
- **テンポ**: ゆっくり（BPM 60〜90程度）
- **長さ**: 1分〜3分程度のバリエーション

#### 推奨楽曲構成例
1. **短尺用（30秒〜1分）**: シンプルなピアノソロ
2. **中尺用（1分〜1分半）**: アコースティックギター
3. **標準用（1分半〜2分）**: ピアノ+ストリングス
4. **長尺用（2分〜2分半）**: アンビエント
5. **超長尺用（2分半〜3分）**: クラシック風オーケストラ

### BGM自動選択ロジック

#### 選択基準
- **動画の長さ**: 画像枚数 × 表示時間（3〜5秒）
- **マッチング方法**: 動画の長さに最も近いBGMを選択
- **例**:
  - 動画45秒 → 短尺用BGM（1分）
  - 動画90秒 → 標準用BGM（1分半〜2分）
  - 動画150秒 → 超長尺用BGM（2分半〜3分）

#### フォールバック
- 動画がすべてのBGMより長い場合: 最長のBGMを選択してループ（Phase 2）
  - Phase 1では最長BGMでフェードアウト

### BGM調整

#### 動画尺とBGMの長さの関係

**ケース1: BGM > 動画**
- BGMが動画より長い場合
- 処理: 動画の長さに合わせてBGMをカット
- フェードアウト: 最後の2〜3秒でフェードアウト

**ケース2: BGM = 動画**
- ほぼ同じ長さ
- 処理: そのまま使用

**ケース3: BGM < 動画**（Phase 2対応）
- BGMが動画より短い場合
- Phase 1: BGMの長さで動画を調整、またはフェードアウトして終了
- Phase 2: BGMをループまたは別のBGMに切り替え

#### フェードアウト仕様
- **開始タイミング**: 動画終了の2〜3秒前
- **フェード曲線**: リニア（線形）またはイージング
- **最終音量**: 0（無音）

### ファイル形式・品質

#### 対応フォーマット
- MP3（推奨）
- AAC
- WAV（サイズが大きいため非推奨）

#### 音質
- **サンプリングレート**: 44.1kHz
- **ビットレート**: 128kbps以上（推奨192kbps）
- **チャンネル**: ステレオ

## 技術仕様

### BGM素材の配置
- **保存先**: `public/assets/bgm/` または `app/assets/bgm/`
- **ファイル名**:
  - `bgm_01_short.mp3`（30秒〜1分）
  - `bgm_02_medium.mp3`（1分〜1分半）
  - `bgm_03_standard.mp3`（1分半〜2分）
  - `bgm_04_long.mp3`（2分〜2分半）
  - `bgm_05_extra_long.mp3`（2分半〜3分）

### メタデータ管理
- **ファイル**: `app/data/bgmMetadata.json`
- **内容**:
```json
[
  {
    "id": "bgm_01",
    "filename": "bgm_01_short.mp3",
    "duration": 60,
    "title": "Gentle Piano",
    "mood": "calm"
  },
  ...
]
```

### 実装ファイル
- `app/lib/bgmSelector.ts`: BGM選択ロジック
- `app/lib/audioProcessor.ts`: 音声処理（カット、フェードアウト）
- `app/data/bgmMetadata.json`: BGMメタデータ

### FFmpeg による音声処理

#### BGMカット + フェードアウト
```bash
ffmpeg -i bgm.mp3 -t 45 -af "afade=t=out:st=42:d=3" output.mp3
```
- `-t 45`: 45秒でカット
- `afade=t=out:st=42:d=3`: 42秒からフェードアウト開始、3秒かけてフェード

#### 動画とBGMの結合
```bash
ffmpeg -i video.mp4 -i bgm.mp3 -c:v copy -c:a aac -shortest output.mp4
```
- `-shortest`: 短い方の長さに合わせる
- `-c:a aac`: 音声をAACでエンコード

## エラーハンドリング

### 想定エラー
- BGMファイルが存在しない
- BGMファイルが破損している
- FFmpeg音声処理失敗

### 対応
- ファイル存在チェック: 起動時に全BGMの存在を確認
- 破損チェック: FFmpegでプローブして検証
- 処理失敗: デフォルトBGMを使用、またはBGMなしで動画生成

## パフォーマンス
- BGM処理は軽量（数秒で完了）
- 動画生成と並列化可能な部分は並列処理

## 制約事項
- BGMは著作権フリーまたはライセンス取得済みのものを使用
- ユーザーによるBGM選択機能はPhase 1では非対応

## セキュリティ
- BGMファイルへの不正アクセス防止（public配下に配置する場合）
- ファイルパスのサニタイズ
