# BGM管理機能 タスク一覧

## タスク

### BGM素材準備

#### 1. BGM素材の調達
- [ ] 著作権フリー音源サイトから5曲をダウンロード
  - 推奨サイト: Pixabay Music, YouTube Audio Library, Incompetech等
- [ ] 楽曲の選定（静かで落ち着いた感動的な曲）
- [ ] 各楽曲の長さを確認・調整:
  - [ ] 短尺用（30秒〜1分）
  - [ ] 中尺用（1分〜1分半）
  - [ ] 標準用（1分半〜2分）
  - [ ] 長尺用（2分〜2分半）
  - [ ] 超長尺用（2分半〜3分）

#### 2. BGMファイルの配置
- [ ] `app/assets/bgm/` ディレクトリを作成
- [ ] BGMファイルをリネームして配置:
  - [ ] `bgm_01_short.mp3`
  - [ ] `bgm_02_medium.mp3`
  - [ ] `bgm_03_standard.mp3`
  - [ ] `bgm_04_long.mp3`
  - [ ] `bgm_05_extra_long.mp3`
- [ ] 音質を確認（128kbps以上、44.1kHz）

#### 3. メタデータ作成
- [ ] `app/data/bgmMetadata.json` ファイル作成
- [ ] 各BGMの情報を記録:
  - id, filename, duration, title, mood
- [ ] メタデータの型定義（TypeScript）

### BGM選択ロジック

#### 4. BGM選択機能
- [ ] `bgmSelector.ts` ファイル作成
- [ ] メタデータ読み込み処理
- [ ] 動画の長さを計算する関数
- [ ] 動画の長さに最も近いBGMを選択するロジック
- [ ] ユニットテスト:
  - [ ] 45秒の動画 → 短尺BGM
  - [ ] 90秒の動画 → 標準BGM
  - [ ] 150秒の動画 → 超長尺BGM

### 音声処理

#### 5. BGMカット・フェードアウト
- [ ] `audioProcessor.ts` ファイル作成
- [ ] FFmpegでBGMをカットする処理
- [ ] フェードアウト処理の実装:
  - [ ] フェード開始タイミング計算（動画終了の2〜3秒前）
  - [ ] FFmpeg afade フィルター適用
- [ ] 処理結果の検証（音声ファイルの長さ確認）

#### 6. 動画とBGMの結合
- [ ] FFmpegで動画とBGMをマージする処理
- [ ] `-shortest` オプションで短い方に合わせる
- [ ] 音声コーデック設定（AAC）
- [ ] 音量調整（必要に応じてラウドネス正規化）

### API統合

#### 7. スライドショー生成APIとの統合
- [ ] `app/api/generate/route.ts` に BGM処理を追加
- [ ] 動画の長さ取得
- [ ] BGM自動選択の呼び出し
- [ ] BGM処理（カット・フェードアウト）
- [ ] 動画+BGMの結合
- [ ] エラーハンドリング

### エラーハンドリング

#### 8. エラー対応
- [ ] BGMファイル存在チェック（起動時）
- [ ] BGMファイル破損チェック（FFmpegプローブ）
- [ ] 処理失敗時のフォールバック:
  - [ ] デフォルトBGM使用
  - [ ] BGMなしで動画生成
- [ ] エラーログの記録

### テスト

#### 9. ユニットテスト
- [ ] BGM選択ロジックのテスト
- [ ] フェードアウト計算のテスト
- [ ] メタデータ読み込みのテスト

#### 10. 統合テスト
- [ ] 短い動画（30秒）でBGM統合テスト
- [ ] 長い動画（2分）でBGM統合テスト
- [ ] BGMが動画より長い場合のテスト
- [ ] フェードアウトの動作確認（実際に再生して確認）

### ドキュメント

#### 11. BGMライセンス情報
- [ ] `app/data/bgmLicenses.md` を作成
- [ ] 各BGMのライセンス情報を記録
- [ ] クレジット表記の要否確認

## 備考
- BGM素材は著作権に十分注意すること
- フェードアウトの長さ（2〜3秒）は実際に聴いて調整
- 音量のバランスも重要（BGMが大きすぎない）
