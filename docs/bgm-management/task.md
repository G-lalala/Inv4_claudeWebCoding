# BGM選定編集機能 タスク一覧

## ユーザー側タスク（実装前に準備が必要）

### BGM素材準備

#### 1. BGM素材の調達と配置
- [ ] 著作権フリー音源サイトから5曲をダウンロード
  - 推奨サイト: Pixabay Music, YouTube Audio Library, Incompetech等
- [ ] 楽曲の選定基準:
  - 静かで落ち着いた感動的な曲
  - ピアノ、アコースティック、アンビエント、クラシック等
  - テンポ: ゆっくり（BPM 60〜90程度）
- [ ] 各楽曲の長さを確認・必要に応じて調整:
  - 短尺用（30秒〜1分）
  - 中尺用（1分〜1分半）
  - 標準用（1分半〜2分）
  - 長尺用（2分〜2分半）
  - 超長尺用（2分半〜3分）

#### 2. BGMファイルの配置
- [ ] `app/assets/bgm/` ディレクトリを作成
- [ ] BGMファイルをリネームして配置:
  - `bgm_01_short.mp3`（30秒〜1分）
  - `bgm_02_medium.mp3`（1分〜1分半）
  - `bgm_03_standard.mp3`（1分半〜2分）
  - `bgm_04_long.mp3`（2分〜2分半）
  - `bgm_05_extra_long.mp3`（2分半〜3分）
- [ ] 音質を確認（128kbps以上、44.1kHz、ステレオ）

#### 3. メタデータ作成
- [ ] `app/data/bgmMetadata.json` ファイルを作成
- [ ] 各BGMの情報を記録（id, filename, duration, title, mood）
- [ ] 例:
```json
[
  {
    "id": "bgm_01",
    "filename": "bgm_01_short.mp3",
    "duration": 60,
    "title": "Gentle Piano",
    "mood": "calm"
  }
]
```

#### 4. ライセンス情報の記録
- [ ] `app/data/bgmLicenses.md` を作成
- [ ] 各BGMのライセンス情報を記録
- [ ] クレジット表記の要否を確認
